# Тестирование в продакшене

[Codebattle](https://codebattle.hexlet.io/) — тестируемый проект

## О проекте

Codebattle — игра, в которой два программиста одновременно выполняют одну задачу на разных языках программирования. Кто выполнил быстрее, тот побеждает.

## Содержание файлов

- requirements.yml - описание функциональных, нефункциональных и неявных требований проекта
- test-cases.yml - подробные тест-кейсы для проведения тестирования
